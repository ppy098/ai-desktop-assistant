# AI Desktop Assistant（AI 桌面助手）

一个运行在 Windows 上的开源桌面助手：用一句自然语言，让 AI 帮你**打开软件、创建文件、浏览器搜索、打开网址、截屏、读写剪贴板、查看电脑状态、一键优化内存**。

> 示例对话
> “打开记事本” → 自动启动记事本
> “在桌面上创建一个叫 todo.txt 的文件，内容写：买牛奶” → 自动创建文件
> “帮我搜一下青岛今天的天气” → 自动打开浏览器搜索
> “打开 www.baidu.com，然后截个屏” → 打开网页并保存截图到桌面
> “现在几点”“看看剪贴板”“电脑状态”“优化内存” → 直接回答

## 功能特性

* 自然语言指令，基于在线大模型（OpenAI 兼容接口，支持豆包 / DeepSeek / OpenAI / **本地 Ollama** 等）
* 内置工具：启动应用程序、创建文本文件、浏览器搜索、打开网址、截屏保存、剪贴板读写、电脑状态查看、一键内存优化、打开常用文件夹
* **未配置 API Key 时自动切换为本地规则模式**：打开软件、建文件、搜索、截屏、看时间、读剪贴板、查电脑状态、优化内存都能直接用
* **右下角悬浮球常驻**：单击从球后面展开对话面板（非独立窗口），可拖动，系统托盘双入口
* **软件内「设置」界面**：API Key / 接口地址 / 模型 / 搜索引擎直接填写保存，支持一键「测试连接」，无需手动编辑配置文件
* **5 套个性化皮肤**：浅色、深色、薄荷、海洋、日落，切换即时生效
* **快捷指令按钮**：面板里一键截屏 / 看时间 / 看剪贴板 / 看电脑状态 / 优化内存 / 清空对话
* **对话记录自动保存**：重启后回显最近 20 条记录
* 基于 PySide6 的图形界面，纯 Python，结构清晰，适合二次开发
* 密钥保存在本机 `settings.json`（或 `.env`），不会被提交到仓库

## 快速开始

### 1. 环境要求

* Windows 10 / 11（64 位）
* Python 3.10 及以上（开发环境使用 3.13）

### 2. 获取代码并安装依赖

```
git clone https://github.com/你的用户名/ai-desktop-assistant.git
cd ai-desktop-assistant
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 3. 配置 AI（可选，三种方式任选）

**方式一：软件内配置。** 启动程序后，右键悬浮球（或托盘图标）→ 设置，填入：

* **API Key**：豆包（火山方舟）为 32 位，在火山引擎方舟控制台申请（需账号实名认证并开通模型）
* **接口地址**：豆包默认 `https://ark.cn-beijing.volces.com/api/v3`
* **模型**：如 `doubao-seed-1-6-250615` 或推理接入点 `ep-xxx`
* 点「测试连接」验证通过后点「保存」，配置写入本机 `settings.json`

**方式二：本地大模型（Ollama，免费、不联网、无需实名）。**

1. 安装 [Ollama](https://ollama.com/download)
2. 拉取一个中文小模型：`ollama pull qwen2.5:1.5b`（约 1GB，低配电脑也能跑）
3. 软件设置里填：接口地址 `http://127.0.0.1:11434/v1`，API Key 随便填（如 `ollama`），模型 `qwen2.5:1.5b`
4. 老显卡（如 NVIDIA 930M）可能不支持新版 CUDA 加速，报 `CUDA error: PTX unsupported` 时，设置环境变量 `OLLAMA_LLM_LIBRARY=cpu` 后重启 Ollama，改用 CPU 推理即可

**方式三：手动 `.env`。** 复制 `.env.example` 为 `.env` 后编辑（仅在 `settings.json` 不存在时生效）：

```
Copy-Item .env.example .env
notepad .env
```

不配置也可以运行，程序会使用本地关键词规则处理指令。

### 4. 启动

```
python -m ai_assistant
```

或直接运行 `scripts\run.ps1`。

## 使用示例

| 你说的话                     | 执行的动作            |
| ------------------------ | ----------------- |
| 打开记事本 / 打开计算器           | 启动对应程序           |
| 搜一下 “青岛天气”              | 浏览器打开搜索引擎        |
| 打开 www.baidu.com        | 浏览器直接打开该网址       |
| 在桌面创建 hello.txt，内容是你好    | 创建文本文件           |
| 截屏 / 帮我截图                | 全屏截图并保存到桌面        |
| 现在几点 / 今天几号              | 回答当前日期时间         |
| 看看剪贴板                     | 读取剪贴板文本          |
| 复制：明天的会议改到三点            | 把文本写入剪贴板         |
| 电脑状态 / 内存还剩多少            | 显示内存、磁盘、处理器、电池    |
| 优化内存 / 一键内存优化           | 清待机列表+文件缓存+整理工作集   |
| 打开桌面 / 打开下载文件夹          | 打开对应文件夹          |
| 打开计算器，再搜一下 C++ 教程        | 一条指令可执行多个动作      |

## 安全说明

* 本程序可以在你的电脑上启动程序、创建文件、截屏、整理进程内存，请勿在不可信的自动化环境中授予其权限。
* 内存优化不会结束任何进程。普通权限下只整理工作集（约 200~300MB）；点击按钮时会弹出一次 UAC 授权，允许后以管理员身份清空 Windows 待机内存列表与系统文件缓存，释放量可达 1GB 以上。
* 文件创建默认只允许在当前用户目录下，避免误操作系统目录。
* API Key 属于敏感信息：保存在本机 `settings.json`（或 `.env`），两者均已通过 `.gitignore` 排除，不会提交到 GitHub，请勿把 Key 分享给他人。
